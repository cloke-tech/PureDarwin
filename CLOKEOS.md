# ClokeOS changes

This branch holds the changes [ClokeOS](https://github.com/cloke-tech/ClokeOS) makes on top of PureDarwin (base: `1bbaeb2`).
It is a fork used by ClokeOS; thank you to the original authors. The changes follow the licence of the upstream project.
Patch files and the build scripts that apply them live in ClokeOS under `clokeos-darwin/kext/ and libobjc/`.
Realtek RX recovery, USB HID stall fix, HD audio amp fix, ACPI topology fix, objc4 class_ro const fix.
